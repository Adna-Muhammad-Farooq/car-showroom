# Car Showroom

A small car showroom website I built while learning how to create and publish websites.

The website presents a simple showroom layout with featured cars, services, contact information, and a language switcher for English and Swedish.

## Features

* Responsive single-page car showroom layout
* Navigation bar with Home, Inventory, Services, and Contact sections
* Hero section introducing the showroom
* Featured car cards
* Additional car image gallery
* Services section
* Contact information and social media links
* Hover effects on buttons and car cards
* Smooth scrolling between sections
* English and Swedish language support
* Language preference saved using `localStorage`

## Built with

* HTML5
* Tailwind CSS
* JavaScript
* i18next
* HTML/CSS hover and transition effects

## Running it

Clone the repository:

```bash
git clone https://github.com/Adna-Muhammad-Farooq/car-showroom.git
```

Then open `index.html` in a browser.

Nothing needs to be installed because the project uses CDN-hosted libraries.
